# WolfEdge Labs
# Design Direction & Frontend Experience

This is NOT a generic landing page.

This is NOT a SaaS template.

This is NOT a crypto landing page.

This is NOT a collection of cards.

The objective is to create an award-quality, highly memorable website for a serious blockchain infrastructure and product company.

The site should feel closer to:

Apple product storytelling
+
Palantir
+
Porsche
+
Linear
+
Stripe
+
Bloomberg terminals
+
high-end industrial design

than:

generic SaaS
generic Web3
generic crypto
Framer template
Tailwind template
AI-generated landing page

---

# 1. MOST IMPORTANT RULE

Do not design the website section-by-section in isolation.

The entire homepage must feel like ONE continuous visual experience.

The transitions between sections are part of the design.

A visitor should feel like they are moving through an infrastructure system.

The page should progressively reveal:

Infrastructure
→
Products
→
Canton
→
Ecosystem
→
Operations
→
Company

---

# 2. DESIGN VARIANCE

Use high design variance.

Do NOT make every section:

eyebrow
heading
paragraph
3 cards

Do NOT repeat:

heading on top
three equal cards underneath

Do NOT repeat:

left text
right image

Do NOT repeat:

centered heading
grid

Every major section should have a different composition.

Use:

- asymmetric layouts
- horizontal compositions
- pinned scroll sections
- oversized typography
- vertical transitions
- layered diagrams
- editorial compositions
- full viewport moments
- horizontal scrolling where appropriate
- sticky visualizations
- overlapping elements
- depth
- controlled negative space
- data visualization
- product-scale visual storytelling

---

# 3. VISUAL DENSITY

Overall density:

Low to medium.

Do not put every piece of copy on the screen.

The website has a lot of information.

The solution is NOT to show everything at once.

Use progressive disclosure.

Show:

headline
→
short explanation
→
visual
→
interaction
→
technical detail when needed

Users who want depth should be able to discover it.

---

# 4. DARK THEME

The entire page should live inside one dark atmospheric world.

Do not make every section the same black rectangle.

Use subtle tonal changes.

Base:

#07090B

Other tones:

#0B1015
#0F151B
#121A21
#17212A

Text:

#F5F7FA
#C4CBD3
#7F8994

Accent:

Electric blue / cold cyan.

Do not use rainbow gradients.

Do not use purple as the primary accent.

Do not use neon cyberpunk lighting.

Do not cover the page in glow.

# 25. MOTION SYSTEM

Motion should be a major part of the experience.

But motion must communicate something.

Use:

ScrollTrigger
Motion
CSS scroll-driven animations
IntersectionObserver

Do NOT use:

window.addEventListener("scroll")

Do not animate React state on every scroll event.

---

# 26. MOTION LANGUAGE

Motion should feel:

slow
precise
mechanical
physical
expensive

Use:

- 400–1000ms transitions
- smooth easing
- layered parallax
- opacity reveals
- scale transitions
- line drawing
- masked reveals
- sticky sections
- horizontal movement
- depth changes

Avoid:

bounce
elastic startup animations
spinning cards
random floating objects
excessive mouse-follow effects

# 28. TRANSITIONS BETWEEN SCENES

This is extremely important.

Do not use:

section A ends

margin

section B begins

Instead create visual continuity.

Examples:

A line from the infrastructure visualization becomes the line connecting products.

A product visualization becomes the Canton network.

The Canton network becomes the ecosystem orbit.

The orbit becomes infrastructure telemetry.

Telemetry fades into the company timeline.

The timeline becomes the final CTA.

The website should feel like one visual system transforming.

REDESIGN IT.

If YES:

REDESIGN IT.

REDESIGN IT.

# 34. COLOR DISCIPLINE

Use one dominant accent family.

Blue/cyan is preferred.

Do not introduce a new accent color for every product.

Products can have subtle tonal identities but must still feel part of WolfEdge.

The page must feel like one brand.

---

# 35. IMAGE / 3D RULE

Do not add random illustrations just to fill empty space.

Every visual must communicate something.

If 3D is used:

Use it for:

architecture
infrastructure
products
systems
network relationships

Not decorative cubes.

If generated visuals are needed, create them specifically around WolfEdge's concepts.

---

# 36. RESPONSIVE DESIGN

Desktop should be cinematic.

Tablet should preserve hierarchy.

Mobile should NOT simply stack the desktop layout.

Recompose sections for mobile.

Important visual interactions must have a mobile equivalent.

Avoid:

horizontal overflow
tiny text
desktop diagrams squeezed into phones
massive animations that hurt performance

---

# 37. PERFORMANCE

The site should feel premium because of design, not because it destroys performance.

Prefer:

transform
opacity
GPU-friendly animations
lazy-loaded media
optimized assets

Avoid:

huge videos
continuous particle simulations
heavy canvas effects everywhere
scroll listeners
layout-triggering animation

---

# 38. ACCESSIBILITY

Maintain readable contrast.

Motion should respect prefers-reduced-motion.

Interactive elements need keyboard accessibility.

Do not sacrifice usability for visual effects.

---

# 39. FINAL DESIGN OBJECTIVE

The visitor should leave understanding:

WolfEdge operates infrastructure.

WolfEdge builds products.

WolfEdge understands blockchain systems deeply.

WolfEdge is building a connected product and infrastructure stack around Canton.

The website should make the company feel:

serious
technical
premium
credible
ambitious
quietly confident

The goal is not:

"Wow, cool crypto website."

The goal is:

"These people actually build and operate infrastructure."

That is the feeling the entire design should create.
